API 设计规范(测试语料)

哨兵:SOP_HTML_SENTINEL_73 —— 本文件是 MCP 手测语料,内容为虚构示例。

路径与方法

资源路径使用小写复数名词,层级不超过三层。获取用 GET,创建用 POST,整体替换用 PUT,删除用 DELETE。禁止在 GET 请求里做任何写操作。

分页约定

列表接口统一使用 page 和 size 两个参数,页码从一开始,单页上限一百条。响应体必须携带总条数字段,方便前端渲染页码。

错误响应

错误统一返回三件套:机器可读的错误码、给开发者看的原因、给最终用户看的提示文案。错误码采用大写下划线风格,例如 QUOTA_EXCEEDED。

HTTP 状态使用场景
400参数校验失败、业务规则拒绝
401凭证缺失或无效
404资源不存在,注意不要泄露资源是否曾经存在
429限流或配额用尽,响应头带重试建议

版本策略

大版本进路径前缀,例如 /v1/。字段级演进保持向后兼容:只加字段不改语义,废弃字段先标记两个迭代再移除。
